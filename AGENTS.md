# An adaptive bookreader app

## Tmp dir
- use tmp in project root for testing files
## Format
- trim trailing spaces
- add new lines to last line in file
- max line length 100 chars
## Code style
- stick to Haskell Best practices (high order function, phantom types etc)
- avoid copypaste - generarize similar code snippets
- use multiline literal string for long string inside miso views (wrap)
